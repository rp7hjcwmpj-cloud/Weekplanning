☁️ Microsoft 365 — Gedeelde opslag

Koppel de app aan een SharePoint-lijst zodat alle docenten, leerlingen en de coördinator dezelfde actuele data zien. Vul onderstaande waarden in vanuit de Azure App Registration en SharePoint.

Benodigde stappen (eenmalig door IT-beheerder):
1. Maak een App Registration aan in Azure Portal → geef Sites.ReadWrite.All API-toestemming → kopieer de Client ID & Tenant ID hierboven.
2. Maak een SharePoint-lijst aan genaamd WeekplanningData met één extra kolom Value (meerdere regels tekst). Vul de volledige site-URL en de lijstnaam hierboven in.
3. Host deze HTML op Azure Static Web Apps of een SharePoint-pagina en voeg de URL toe als redirect URI in de App Registration.
4. Voeg de app toe als tabblad in Teams via Tabblad toevoegen → Website → URL.

📋 Aanwezigheid — Exporteren

Exporteer een overzicht van de aanwezigheidsregistratie over het hele schooljaar naar Excel. Het bestand bevat vier tabbladen: Verwacht, Aanwezig, Afwezig en Gewijzigd — met leerlingen in rijen en weeknummers in kolommen.

Legenda:
✓ Aanwezig = aangevinkt met groen vinkje
✕ Afwezig = aangevinkt met rood kruis
● Gewijzigd = aangevinkt met oranje rondje (bijv. te laat of eerder weg)
Getallen = aantal lessen (lesuren) op de betreffende dag(en) in die week
